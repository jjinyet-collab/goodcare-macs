# VILAC Store 구매 로직 · PG 심사 준비

`v2/shop.html`은 비락 / 굿케어맥스 / 전체 스토어의 화면과 구매 로직을 한 파일에 담은 시안이에요.

- **테스트 모드(`CONFIG.mode = 'demo'`):** 결제·로그인·주문을 이 브라우저(localStorage) 안에서 흉내 내요.
- **운영 모드(`'live'`):** 같은 화면이 서버 API, 카카오, 토스페이먼츠를 호출해요.

## 1. 화면 흐름

```
브랜드 페이지(index.html) ─ 헤더 [비락 | 굿케어맥스 | 전체] · [구매하기]
        │
        ▼
상품 목록 #/list?brand=vilac|gcm|all  (카테고리 · 정렬 · 관심상품 · 장바구니 담기)
        │
        ▼
상품 상세 #/product/:id  (구성 선택 · 한 번 구매/정기배송 5% · 수량 · 장바구니/바로 구매)
        │
        ▼
장바구니 #/cart  (선택·수량·삭제 · 3만원 이상 무료배송 안내)
        │  로그인 안 됨
        ├──────────────▶ 로그인 #/login ─ 카카오 로그인 / 이메일 로그인 / 회원가입 / 비회원 주문
        ▼
주문·결제 #/checkout  (주문자 · 배송지(우편번호 검색) · 쿠폰 · 적립금 · 결제수단 · 결제 동의)
        │  주문 생성(PENDING) → PG 결제창
        ▼
#/pay/success → 서버 결제 승인(금액 검증) → PAID → 주문 완료 #/complete/:orderId
#/pay/fail    → FAILED, 장바구니 유지
        ▼
마이페이지 #/my/(home|orders|wish|coupons|profile)  ·  비회원 주문조회 #/guest
```

## 2. 회원

| 구분 | 처리 |
|---|---|
| 이메일 가입 | 이메일 형식, 비밀번호 8~20자(영문·숫자·특수문자 중 2종 이상), 휴대폰 문자 인증, 필수 약관 3종(만 14세·이용약관·개인정보) + 선택 마케팅 수신 |
| 카카오 가입·로그인 | 카카오 인가코드 → **서버**에서 토큰 교환·프로필 조회 → `kakaoId`로 회원 조회 또는 생성. 첫 로그인이면 `#/kakao-info`에서 이름·휴대폰·약관 동의를 받아요. |
| 가입 혜택 | 신규가입 쿠폰 2,000원(1만원 이상 구매 시) 자동 발급 |
| 장바구니 | 비회원 장바구니는 브라우저에 두고, 로그인하면 회원 장바구니로 합쳐요(같은 상품·구성은 수량 합산). |
| 탈퇴 | 진행 중인 주문(결제 완료·준비중·배송중)이 있으면 막아요. 쿠폰·적립금은 소멸해요. |
| 비회원 주문 | 주문조회 비밀번호(숫자 4~6자리)를 받고, 주문번호 + 휴대폰 + 비밀번호로 조회해요. |

## 3. 금액 계산 (서버가 최종 계산)

- 상품 금액 = Σ(단가 × 수량). 정기배송 단가는 판매가 × 0.95를 10원 단위로 반올림해요.
- 배송비: 상품 금액 30,000원 이상이면 무료, 미만이면 3,000원이에요.
- 쿠폰: 최소 주문금액 이상일 때만 적용하고, 상품 금액을 넘지 않아요.
- 적립금: 보유액, 그리고 (상품 금액 − 쿠폰) 이하에서만 쓸 수 있어요.
- **결제 금액 = 상품 + 배송비 − 쿠폰 − 적립금**
- 적립: 상품 금액의 1%예요. 배송 완료 후 확정하고, 취소되면 회수해요.
- 품절·출시 예정 상품은 계산에서 빠지고 주문할 수 없어요.
- **브라우저가 보낸 금액은 믿지 않아요.** 결제 승인 직전에 서버가 다시 계산한 주문 금액과 PG 결제 금액이 다르면 승인하지 않아요.

## 4. 주문 상태

```
PENDING(결제 대기) ─▶ PAID(결제 완료) ─▶ PREPARING(상품 준비) ─▶ SHIPPING(배송중) ─▶ DELIVERED(배송 완료)
      │                     │                    │                                          │
      ▼                     └──── 고객 취소 ─────┴─▶ CANCELLED(전액 환불, 쿠폰 복구)          └─▶ RETURN_REQ(교환·반품)
   FAILED
```

- 고객은 출고 전(PAID·PREPARING)에만 마이페이지에서 바로 취소할 수 있어요. 출고 이후는 반품으로 처리해요.
- 결제 승인이 되면 쿠폰을 사용 처리하고, 장바구니에서 주문한 상품만 빼요.

## 5. 운영 전환 시 서버 API (Node/Vercel/Cloudflare 등)

| 메서드 | 경로 | 설명 |
|---|---|---|
| POST | /auth/signup · /auth/login · /auth/logout | 세션(HttpOnly 쿠키), 비밀번호는 bcrypt/argon2로 저장 |
| GET | /oauth/kakao?code= | 카카오 토큰 교환 → 회원 조회·생성 → 세션 발급 → 스토어로 리다이렉트 |
| POST | /auth/sms · /auth/sms/verify | 휴대폰 인증번호(3분 만료, 5회 제한) |
| GET/PUT | /me · /me/addresses · /me/wish | 회원정보, 배송지, 관심상품 |
| GET/PUT | /cart | 회원 장바구니 |
| POST | /orders/quote | 금액 계산 |
| POST | /orders | 주문 생성(PENDING) → orderId, amount 반환 |
| POST | /payments/confirm | `paymentKey, orderId, amount` → 금액 검증 → 토스 승인 API(시크릿 키) → PAID |
| POST | /payments/webhook | PG 웹훅(가상계좌 입금, 취소) 반영 |
| POST | /orders/:id/cancel | 출고 전 취소 → PG 취소 API |
| GET | /orders · /orders/guest | 회원·비회원 주문 조회 |

화면 쪽에서 바꿀 곳은 `shop.html`의 `CONFIG`(apiBase, kakaoJsKey, tossClientKey, mode)와 `API` 객체 메서드뿐이에요. 화면 코드는 그대로 써요.

## 6. PG 신청·심사 체크리스트

**신청(비락 명의로 직접 진행)**
- PG사 선택: 토스페이먼츠(추천, 개발 쉬움) / 포트원(여러 PG 통합) / KG이니시스 / NHN KCP
- 서류: 사업자등록증, 통신판매업 신고증, 대표자 신분증 사본, 정산 계좌 통장 사본, 법인인감증명서·사용인감계(법인)
- 간편결제(카카오페이·네이버페이·토스페이)는 PG 계약 후 따로 심사를 받아요.
- 카카오 로그인: Kakao Developers에 앱 등록 → 비즈 앱 전환(사업자 정보) → 이메일·전화번호 동의항목 검수

**사이트 심사 항목 (shop.html에 자리 마련됨 — 노란 표시를 실제 정보로 채우기)**
- [ ] 하단 사업자 정보: 상호, 대표자, 사업자등록번호, 통신판매업 신고번호, 주소, 고객센터 번호·운영시간, 개인정보보호책임자
- [ ] 이용약관 · 개인정보처리방침 · 교환/환불 정책 페이지 (`#/doc/terms`, `#/doc/privacy`, `#/doc/refund`)
- [ ] 상품별 판매가, 배송비, 상품정보 제공고시(식품유형, 제조원, 원재료, 영양성분, 보관방법)
- [ ] 회원가입 시 필수·선택 약관 분리 동의, 만 14세 확인
- [ ] 결제 전 주문 내용 확인 및 결제 동의 체크
- [ ] 실제 도메인 + HTTPS로 접속 가능(심사 담당자가 직접 들어와 봐요)
- [ ] 테스트 결제 → 취소까지 정상 동작
- [ ] 당뇨식 표시·광고 문구는 식약처 기준 검토 후 확정

## 7. 아직 예시인 부분

- **비락 우유:** 상온(멸균) 3종(올바른 우유 180mL, 올바른 소화가 잘되는 우유 180mL, 올바른 클래식 우유)으로 구성했고 냉장 우유는 넣지 않았어요. 가격은 외부 판매가를 참고한 예시라 네이버 브랜드스토어 판매가와 상품 사진으로 바꿔야 해요.
- **굿케어맥스:** 그린바나나오트·피스타치오 2종이에요(프로틴 제외). 가격이 예시이고, 피스타치오는 패키지 이미지가 준비중이라 임시 그림이에요.
- **리뷰 수:** 표시된 숫자가 예시예요.
- **문자·카카오 알림톡:** 발송은 아직 문구만 있고 실제로 보내지 않아요.
